# ScienceLab — ห้องทดลองเสมือนจริง

โครงงานเว็บแอปสำหรับเรียนรู้และทดลองวิทยาศาสตร์เสมือนจริง พัฒนาด้วย React, TypeScript และ Vite โดยออกแบบให้ใช้งานได้บน Windows, macOS, Android และ iOS ผ่านเว็บเบราว์เซอร์

## เริ่มต้นใช้งาน

ต้องติดตั้ง Node.js ก่อน จากนั้นเปิดเทอร์มินัลที่โฟลเดอร์โปรเจกต์แล้วรัน:

```bash
npm install
npm run dev
```

คำสั่งอื่น:

- `npm run build` สร้างไฟล์สำหรับนำไปเผยแพร่ใน `dist/`
- `npm run preview` เปิดดูผลลัพธ์จาก build ในเครื่อง
- `npm run typecheck` ตรวจชนิดข้อมูล TypeScript

## โครงสร้างหลัก

```text
src/
  app/                 ตั้งค่าแอปและเส้นทาง
  components/          คอมโพเนนต์ใช้ซ้ำ เช่น ปุ่มและแถบนำทาง
  features/labs/       ฟังก์ชันและหน้าจอการทดลอง
  pages/               หน้าแต่ละส่วนของเว็บ
  styles/              ตัวแปรธีมและสไตล์ส่วนกลาง
  types/               ชนิดข้อมูลที่ใช้ร่วมกัน
  assets/              รูปภาพและไฟล์ประกอบ
```

## แนวทาง responsive

- ใช้เลย์เอาต์ยืดหยุ่นและ breakpoint ใน CSS เพื่อรองรับจอใหญ่ แท็บเล็ต และมือถือ
- ควบคุมการทดลองด้วยปุ่มและ input ที่ใช้งานได้ทั้งเมาส์และ touch
- ทดสอบในเบราว์เซอร์สมัยใหม่บน Windows/macOS และ Safari/Chrome บน Android/iOS

## เพิ่มการทดลอง

สร้างโฟลเดอร์ย่อยใน `src/features/labs/` สำหรับแต่ละหัวข้อ โดยแยกส่วน UI, logic การจำลอง และชนิดข้อมูลออกจากกัน แล้วเชื่อมเข้ากับหน้าใน `src/pages/`
